# market-key-levels-pine

TradingView用 Pine Script v6 インジケーター  
**相場の重要な節目を自動で表示します**

前日高安・ピボット・東京/ロンドン/NYセッション高安・キリ番（心理的節目）をまとめて表示し、節目での反発・失敗パターンに売り買いサイン（矢印）を出すインジケーターです。

## 特徴

- **前日の高値・安値・終値・始値** を表示
- **前週の高値・安値・今週始値** を表示
- **標準ピボットポイント**（PP / R1 / R2 / S1 / S2）
- **東京・ロンドン・NYセッション** の高値・安値を自動記録
- セッション中はボックスでリアルタイムに高安を表示
- **キリ番（心理的節目）** を任意の間隔で表示（例: 50ドル刻み）
- 各ライン・ラベルの表示/非表示を個別に切り替え可能
- タイムゾーンを `Asia/Tokyo` に固定して正確に判定
- **節目での売り買いサイン**（赤の↓＝売り／緑の↑＝買い）を表示し、アラートにも対応

## 対応銘柄

- ゴールド（XAUUSD）
- 為替（USDJPYなど）
- 株価指数 など、TradingViewで扱えるほとんどの銘柄

## インストール方法

1. 下記のコードをすべてコピー
2. TradingViewを開き、Pine Editorを開く
3. 既存のコードを消して貼り付け
4. 「チャートに追加」をクリック

## 設定項目

### 前日
- 前日高値 / 前日安値 / 前日終値 / 前日始値

### 週
- 前週高値 / 前週安値 / 今週始値

### ピボット
- ピボット全体の表示切り替え
- R2 / R1 / PP / S1 / S2 を個別に表示切り替え

### セッションボックス
- 東京時間ボックス（デフォルト: 09:00-18:00）
- ロンドン時間ボックス（デフォルト: 16:00-01:00）
- NY時間ボックス（デフォルト: 21:00-06:00）
- 各セッションの背景色

### キリ番（心理的節目）
- キリ番の表示切り替え
- 間隔（例: 50 や 100）
- 上下に表示する本数

### サイン

表示中の節目（前日・前週・ピボット・セッション高安・現在値の上下2本のキリ番）を対象に、次の3パターンで判定します。

| パターン | 表示 | 内容 |
|----------|------|------|
| ヒゲ反転 | ヒゲ | 節目に届いたあと長いヒゲで押し戻され、終値が節目の手前に戻った足 |
| ダブルトップ/ボトム | DT / DB | 同じ節目付近に近い高値（安値）が2回でき、間に一定以上の谷（山）がある形 |
| 抜け失敗 | 失敗 | 節目に2回以上跳ね返され、終値で抜けないまま節目から離れ始めた時点 |

- 同じ足で複数のパターンが成立した場合は、DT/DB → 失敗 → ヒゲ の順で1つだけ表示します。
- 同じ節目で連続してサインが出ないよう、クールダウン（本数）を設けています。
- DT/DBはピボット確定を待つため、2つ目の山（谷）から「ピボット左右本数」分遅れて表示されます。
- サインは足の確定時に出ます（確定前は表示されません）。
- 設定項目（「【サイン】」グループ）
  - サイン表示 / ヒゲ反転 / ダブルトップ・ボトム / 抜け失敗 のオンオフ
  - ATR期間、節目への接近許容、節目の突き抜け許容（いずれもATR倍）
  - ヒゲ/実体の比率、ヒゲの最小長（ATR倍）
  - ピボット左右本数、ダブルの最大間隔、ダブルの谷の深さ
  - 抜け失敗の観測本数、最小タッチ回数、離脱判定
  - 同じ節目のクールダウン（本）

### アラート

「売りサイン」「買いサイン」の2種類を、TradingViewのアラートから設定できます。

## バージョン履歴

| バージョン | 内容 |
|------------|------|
| Ver7 | 節目での売り買いサイン（ヒゲ反転・ダブルトップ/ボトム・抜け失敗）とアラートを追加 |
| Ver6 | タイムゾーンをAsia/Tokyoに固定、ボックスの重複を解消 |
| Ver5 | セッション高安を「直近終了セッション」の値に修正 |
| Ver4 | キリ番（心理的節目）を追加 |
| Ver3 | アジア→東京に変更、ロンドン時間を追加 |
| Ver2 | セッションボックス対応 |
| Ver1 | 初版 |
