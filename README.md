# market-key-levels-pine

TradingView用 Pine Script v6 インジケーター  
**相場の重要な節目を自動で表示します**

前日高安・ピボット・東京/ロンドン/NYセッション高安・キリ番（心理的節目）をまとめて表示するインジケーターです。

## 特徴

- **前日の高値・安値・終値・始値** を表示
- **前週の高値・安値・今週始値** を表示
- **標準ピボットポイント**（PP / R1 / R2 / S1 / S2）
- **東京・ロンドン・NYセッション** の高値・安値を自動記録
- セッション中はボックスでリアルタイムに高安を表示
- **キリ番（心理的節目）** を任意の間隔で表示（例: 50ドル刻み）
- 各ライン・ラベルの表示/非表示を個別に切り替え可能
- タイムゾーンを `Asia/Tokyo` に固定して正確に判定

## 対応銘柄

- ゴールド（XAUUSD）
- 為替（USDJPYなど）
- 株価指数 など、TradingViewで扱えるほとんどの銘柄

## インストール方法

1. 下記のコードをすべてコピー
2. TradingViewを開き、Pine Editorを開く
3. 既存のコードを消して貼り付け
4. 「チャートに追加」をクリック

## 設定項目

### 前日
- 前日高値 / 前日安値 / 前日終値 / 前日始値

### 週
- 前週高値 / 前週安値 / 今週始値

### ピボット
- ピボット全体の表示切り替え
- R2 / R1 / PP / S1 / S2 を個別に表示切り替え

### セッションボックス
- 東京時間ボックス（デフォルト: 09:00-18:00）
- ロンドン時間ボックス（デフォルト: 16:00-01:00）
- NY時間ボックス（デフォルト: 21:00-06:00）
- 各セッションの背景色

### キリ番（心理的節目）
- キリ番の表示切り替え
- 間隔（例: 50 や 100）
- 上下に表示する本数
